# Zora Star 产品壳原型

## 当前范围

`codex/canvas-c` 提供桌面端 `/image`、`/video` 和 `/canvas` 三个入口，根路径跳转到 `/image`。本轮是本地交互原型，不发布、不调用生图或生视频接口，也不修改数据库、鉴权、画布坐标、节点、Agent 和工作流协议。

## 产品侧栏

侧栏默认宽 60px，仅显示品牌 Logo、导航图标和头像；点击顶部 Logo 后展开到 240px，再次点击收起。鼠标悬停、离开和键盘焦点不会改变展开状态。侧栏与产品内容区使用相同的浅色背景，展开过程占用正常布局空间并同步压缩内容区，不覆盖画布，也不形成独立的视觉分区。

## 生图与生视频

- 生图页只提供参考图、提示词、模型、比例和分辨率。
- 生视频页提供参考图、提示词、模型、比例、分辨率和时长。
- 两个页面不显示重复标题栏和清空入口，任务区占满输入框以外的右侧空间；新版本首次进入为空白状态。
- 两个页面只显示任务指令、等待、生成中、成功和失败状态，不提供通用聊天回复。
- 任务使用互相独立的 `v2` 浏览器存储键，仅保存模拟数据；旧 `v1` 记录不迁移，提交、重试和刷新恢复均不发送网络请求。

## 画布接入

既有画布迁至 `/canvas`，宽度随产品内容区变化。产品壳只把原固定到浏览器视口的主要控件改为相对内容区定位，既有创作画布、工作流、Agent 和节点交互继续沿用原实现。

## 本地预览

```bash
npm ci
npm run dev
```

默认访问 `http://localhost:3001/image`。原型不包含移动端抽屉，也不会生成真实媒体或产生模型费用。
