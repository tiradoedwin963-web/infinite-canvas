# LingkeAI 无限画布开发说明

## 当前交付

项目提供“创作”和“工作流”两套全屏浅色点阵无限画布。创作模式保留底部多模式 AI 输入组件和覆盖式画布 Agent 侧栏；文本、图片和视频模式均接入 LingkeAI，每次提交会把文字、参考图和生成结果拆成独立节点并自动连线，画布 Agent 使用 GPT-5.6 Sol 先通过问题明确需求，再通过受限操作创建、整理或生成节点。工作流模式既支持手动创建和逐个运行，也支持 Agent 把完整剧本原子拆成全部分镜工作流，经用户确认后按依赖批量运行；左上角模式切换会记住上次选择，两种模式的节点与对话数据完全隔离。

本地开发默认继续使用浏览器存储；生产部署启用应用账号后，工作流项目、对话和任务状态写入独立 PostgreSQL，图片与视频写入私有腾讯云 COS。服务端模型密钥始终只由同源 API 读取。

## 分支职责

- `codex/canvas-a`：基础画布背景、坐标变换、平移缩放和基础指针输入。
- `codex/canvas-b`：LingkeAI 输入、生成节点、任务状态、本地恢复和画布 Agent。
- `main`：保留可回退的工程基线。

视口坐标协议保持不变；当前交互将普通滚轮与触控板双指滑动映射为平移，将 `Ctrl + 滚轮`和触控板捏合映射为缩放。后续从 A 向 B 同步基础画布时，仍应使用明确的 Git 提交或快进操作。

## 本地运行

环境要求：Node.js 22.13 或更高版本。

在项目根目录创建 `.env.local`：

```dotenv
LINGKE_BASE_URL=https://api.example.com
LINGKE_API_KEY=your-server-only-key
TRX_VIDEO_BASE_URL=https://trxdoc.xin
TRX_VIDEO_API_KEY=your-server-only-video-key
```

密钥只由同源服务端路由读取，不使用 `NEXT_PUBLIC_` 或 `VITE_` 前缀。启动与验证：

```bash
npm ci
npm run dev
npm run lint
npm test
```

开发服务固定使用 `http://localhost:3001` 并启用严格端口模式。3001 已被其他进程占用时启动会明确失败，不会自动跳到其他端口；这样可以避免浏览器因端口变化读取到另一份 `localStorage` 画布数据。

## 模型与输入

- 文本：GPT-5.6 Sol、Claude Sonnet 5、Gemini 3.1 Pro Preview、DeepSeek V4 Pro、Qwen 3.7 Max。
- 图片：Nano Banana Pro、GPT Image 2、Nano Banana 2、Seedream 5.0 Pro。
- 视频：Seedance 2.0、Seedance 2.0 Fast、Seedance 2.5。
- 默认模型分别为 GPT-5.6 Sol、Nano Banana Pro 和 Seedance 2.0。
- 文本、图片和视频模式均支持图片输入。全局最多 5 张、单张最多 10MB、合计最多 30MB；实际数量同时受所选模型限制。
- 当前图片模型仍受全局 5 张参考图上限约束。
- 图片模式可选画面比例和分辨率，默认 `16:9 / 1K`；视频模式按模型提供有效比例、时长和分辨率，默认 720p。切换图片模型会恢复 `16:9` 默认比例；用户手工选择的其他合法比例仍保留。
- 图片分辨率：Nano Banana Pro 与 GPT Image 2 支持 1K/2K/4K，Nano Banana 2 支持 0.5K/1K/2K/4K，Seedream 5.0 Pro 支持 1K/2K。视频分辨率：Seedance 2.0 支持 480p/720p/1080p/4k，Fast 和 2.5 支持 480p/720p。
- 输入组件在桌面固定宽 614px，收起和普通展开高度分别为 54px、102px；缩略图区域增加 51px，错误提示增加 19px。组件固定距视口底部 20px，窄窗口只缩小宽度以保留两侧 20px 安全边距，不跟随画布缩放。
- 上传按钮在三种模式下始终可见；动态占位文字仅在收起且输入为空时轮播，聚焦展开后完成退场并保持空白，重新收起后才恢复。
- 展开布局固定按“顶部缩略图 → 文字输入 → 错误提示 → 底部操作栏”排列；无图片时直接从文字输入开始。上传、模式、模型、比例、时长、分辨率和发送位于底部 54px 操作栏并保持垂直居中。
- 缩略图为 44px 方形并从左向右排列；展开后缩略图、文字和错误提示使用 20px 左边界，文字可显示在左下上传按钮的正上方。收起时文字仍为两侧按钮保留空间，底部选择区在窄屏下可水平滚动。
- 收起时仍为“上传 + 正文 + 发送”单行布局；窄屏下两侧按钮固定可见，仅中间模式和参数选择区可横向滚动。

## 画布 Agent

- 点击右上角“画布 Agent”打开 320px 覆盖式侧栏；480px 及以下视口中侧栏占满宽度。画布保持原尺寸和视口坐标，不因侧栏开关重定位。
- 侧栏打开时底部创作输入向下退出但不卸载，关闭后恢复原草稿。按 `Escape` 关闭侧栏。
- Agent 运行指令统一位于根目录 `agent.md`，图片生成、短剧工作流和剧本资产库手册分别位于 `tools.md`、`workflow-tools.md` 和 `story-asset-tools.md`。漫剧导演使用 `manga-director-core.md` 作为核心，并按当前阶段只加载情绪节拍、场面调度、镜头规划或连续性检查手册；`shot-common-tools.md` 中的详细公共电影摄影语言只在镜头规划阶段加载，连续性阶段只读取精简检查项，避免扩大其他阶段上下文。漫剧专项位于 `comic-storyboard-tools.md`。
- 图片工具手册仅覆盖 Nano Banana Pro、GPT Image 2、Nano Banana 2 和 Seedream 5.0 Pro，记录选型场景、提示词结构、合法比例、分辨率和最多 5 张参考图的限制。用户未指定图片模型时默认使用 Nano Banana Pro。
- Agent 图片操作在服务端统一校正参数：合法值保持不变，缺失值采用模型默认值；不支持的比例选择同方向最接近值，分辨率选择数值最接近值且同距取较低值，无法解析时回到默认值，未知图片模型直接拒绝。确认卡会展示最终比例、分辨率和调整原因，确认执行时只发送修正后的合法参数。
- 动态模型清单将 `mode` 与 `model` 分字段传给 Agent，`generate_content.model` 只使用真实模型 ID。为兼容旧对话或模型误输出，确认链路会自动移除与当前模式一致的 `text:`、`image:` 或 `video:` 前缀。
- 创作画布的每个新对话从 `intake` 开始，首轮只能提问且不读图、不编辑画布；工作流画布收到完整剧本后可首轮直接创建，只有剧本缺失或关键要求互相矛盾时才询问。服务端会拒绝任何在澄清回复中夹带的读图或画布操作。
- Agent 每轮读取全部节点、位置、尺寸、连线两端侧别、文本、提示词和任务状态。点击画布节点可把它设为当前引用，点击空白处清除引用。
- Agent 需要视觉判断时可按节点 ID 读取图片；单轮最多 5 张、单张最多 10MB、合计最多 30MB。视频只提供提示词和元数据，不抽帧或上传视频。
- 创建节点、修改文本或提示词、移动、缩放、连接和断开连接会自动应用。删除节点和文本、图片、视频生成必须在侧栏确认卡中再次确认。
- 确认按钮点击后会立即显示当前卡片的加载状态。确认载荷缺失的卡片会自动标记失效并说明原因，不再静默忽略点击。
- 当前对话同时存在两个及以上有效待确认项时，侧栏显示“全部确认（N）”。批量确认按消息顺序串行执行删除和文本、图片、视频生成；每项成功后立即标记已确认，遇到首个失败即停止并在批量区显示具体原因，失败项和后续项仍可重试。
- 生成确认后复用底部输入已有的模型参数、图片素材、节点创建和任务轮询流程。单项等待超过 60 秒时会释放按钮并中止本地请求，但远端任务仍可能继续；重试前应先检查画布，避免重复计费。删除正在生成的节点也只停止本地查询。
- 右上角可新建对话或打开历史列表，历史标题自动取首条用户消息的前 24 个字符。每个项目最多保留 20 个对话、每个对话 100 条消息，超限后删除最久未更新的对话；生产环境对话以独立修订号保存，不与画布图保存互相覆盖。
- Agent 请求不再按单条 12,000 字符静默截断，当前选中的最多 20 条消息会原样传给上游；超过浏览器、部署运行时或模型上下文限制时会明确提示拆分，不会把缺失正文伪装成完整输入。
- Agent API 使用 SSE 接收上游 Token 流。侧栏实时显示受控的 `progress_summary`，只包含已识别事实、数量、阶段和简短筛选结论，不展示原始思维链、JSON、节点 ID 或未确认操作；完整响应收齐并通过白名单校验前不会修改画布。内部 `activity` 事件只用于刷新等待时间，不携带模型内容，也不能提前执行操作。上游不支持标准流或没有返回 `progress_summary` 时自动回退为一次受控的阶段完成摘要和最终结果，不伪装成逐 Token 上游流。
- 漫剧导演的剧情节拍、场面调度、镜头规划和连续性检查均使用当前阶段专属的严格 JSON Schema：每次只能返回一个匹配阶段的蛇形字段操作，Schema 中每个字段都按上游严格模式完整声明。镜头的资产、节拍、时长、时间轴和核心摄影字段必须完整；前后链接、空对白/声音和连续性备注等可安全推导字段不进入模型 Schema，由系统规范填充。结构、重复 ID 或摄影错误会指出具体原因，且不会创建半套节点。
- 若上游拒绝严格结构化输出格式、提示上下文超限或返回任意 HTTP 失败，页面只显示经过分类的可执行错误与安全 HTTP 状态，不回显上游原文、系统提示、画布数据或密钥；当前批次不会创建半套节点。
- 剧本分析及人物、场景、道具的每个批次采用活动续时：最多等待 180 秒取得首个上游响应，开始响应后连续 120 秒没有新活动才判定停滞，单批总时长最多 10 分钟。侧栏持续显示当前单次请求的等待秒数；用户停止记为 `stopped`，任一超时记为 `failed`，已完成节点和摘要保留，可发送“继续资产规划”从当前阶段恢复。
- 创作画布与工作流画布使用两套独立对话记录，避免节点 ID 和 Tool 语境串用；图片数据和画布快照不会写入聊天记录。旧版创作单对话记录会自动迁移，刷新后未确认操作失效，必须重新提出。
- 模型只返回白名单 JSON 操作，服务端和客户端均校验操作类型及字段；节点文字按不可信数据处理，不能覆盖系统约束或绕过确认。

## 画布交互

- 普通鼠标滚轮和触控板双指滑动用于横向或纵向平移画布；`Ctrl + 滚轮`和触控板捏合围绕指针位置缩放，范围为 25%–400%。捏合灵敏度为原实现的 1.25 倍；鼠标位于节点主体、删除按钮、左右加号或四角缩放区时仍可操作画布，底部输入组件、节点详情层、类型菜单和 Agent 侧栏继续隔离画布手势。Agent 聊天记录与历史列表独立上下滚动，到达滚动边界也不会带动画布。
- 在画布空白处按住鼠标并拖动超过约 6px 会显示框选区域，松开后选择所有与框选范围相交的节点；连线不会被选中。每次框选替换当前选择，空白单击清除选择。
- 单个节点选中时不显示额外选框；同时选中两个及以上有效节点时才显示灰色虚线总框。拖动任一已选节点或多选总框内的空白区域会整体移动全部已选节点，连线实时更新；实际节点及其删除、缩放、加号和详情操作优先于总框命中。
- 拖动节点：移动节点，连线实时更新。每条连线保存来源和目标各自的左/右端口，移动或缩放后仍使用建立连线时明确选择的端口，不自动切换边缘。
- 文本、图片和视频节点仅在鼠标进入某个角落的 24px 透明命中区时显示该角的 8px 缩放圆点和对应光标；卡片主体悬停或节点选中时不显示缩放边界。文本节点可自由调整宽高，最小为 180×120px；图片和视频保持媒体原始比例，短边最小 96px；所有节点最长边不超过 1200px。
- 图片和视频素材加载后会在当前节点范围内按原始比例收紧逻辑边框，避免透明空白。左右加号、类型菜单、正式连线和拖线预览均读取节点实际宽高，移动或缩放后会立即更新固定端口坐标。
- 每个节点左右各有一个加号：左侧表示上游输入，右侧表示下游输出。单击后可选择文本、图片或视频节点，新节点在对应方向自动连接，并在遇到已有节点时上下避让。
- 文本、图片和视频节点的两个加号默认隐藏；鼠标进入节点卡片、加号附近的扩展命中区或点击卡片时同时显示，移出后立即隐藏。拖线期间所有节点的左右端口都会显示，键盘聚焦到单个加号时也会显示该按钮。
- 从任一加号拖到目标节点的左或右端口可手动连线；必须直接命中端口，节点主体不再作为落点，预览线也不会提前吸附。从右端口拖出表示“当前节点→目标节点”，从左端口拖出表示“目标节点→当前节点”；目标可选左或右端口，支持四种端口组合。自连接和同向重复连接会被拒绝，允许多来源和环形关系。
- 单击正式连线会高亮并在路径中点显示删除按钮；也可按 `Delete` 或 `Backspace` 删除选中连线。输入框、文本域、选择器或可编辑内容聚焦时不响应连线删除快捷键；点击节点或画布空白处清除连线选中。
- `Escape` 或点击画布空白处会取消节点类型菜单或当前拖线。
- 直接单击手动创建的空节点后，底部输入框锁定到该节点类型，但不显示额外选框；多节点框选只用于整体移动，不锁定单个节点编辑器。提交会直接执行并更新当前锁定节点，不会再创建一个重复输出节点。点击空白处取消选中后，底部输入框恢复独立生成流程。
- 双击任意文本节点会打开视口中央编辑层；点击保存或按 `Cmd/Ctrl + Enter` 写回节点，取消、点击遮罩或按 `Escape` 丢弃未保存修改。编辑只更新节点文字及其下游传递内容，不重新调用模型。
- 双击已有素材的图片节点会按完整比例打开中央预览；双击已完成视频节点会打开带播放、进度、音量和全屏控制的播放器，默认不自动播放。空媒体节点不打开详情层。
- 节点详情层固定在视口中央，不跟随画布平移缩放；层内的指针、滚轮和双击事件不会传给画布。
- 已有图片的图片节点直接按原始比例完整展示素材，不裁切，不显示标题、模型、状态页脚或额外卡片边框；删除按钮仅在悬停或键盘聚焦时显示。
- 删除节点：只删除当前节点及其连线，不级联删除其他节点。
- 删除仍在生成的输出节点：只停止本地查询，远端任务无法取消，可能继续产生费用。
- 文本加多张参考图会创建 1 个文本输入节点和每图 1 个图片输入节点；所有输入均连接到每个结果节点。
- 返回多张图片或多个媒体地址时，每个结果创建独立节点。

## 工作流模式

- 工作流模式不显示底部 AI 输入框。双击空白画布可创建文本素材、图片素材、视频素材或通用调度节点；首次进入使用独立空图，不迁移创作模式节点。
- 工作流左上角提供项目选择器，支持新建、切换、重命名、删除和“创建电影语言对照版”。对照版保留剧本分析、资产库、剧情节拍和场面调度，删除旧镜头、视频节点、连续性报告与批量队列，并从镜头规划第 0 批重新开始；原项目保持不变。本地对照版复用 IndexedDB 素材，删除项目时按全部素材引用保护共享数据；生产环境通过专用接口把原图和已有缩略图复制到新项目 COS 对象键，并创建新的资产 ID，删除原项目不会影响对照版。
- 本地开发模式继续使用 `localStorage + IndexedDB`，便于离线调试。生产环境设置 `WORKFLOW_STORAGE_MODE=server` 后必须先登录应用账号：项目图、视口、批量队列与对话写入 PostgreSQL，素材通过短期签名地址直传私有 COS，生成结果由服务端转存 COS；所有查询都按账号所有者过滤，跨账号项目和素材统一返回 `404`。
- 生产环境的图片卡片使用最长边 640px、质量 82% 的 WebP 缩略图，并按账号、资产和内容版本缓存在浏览器 IndexedDB。刷新时最多并发恢复 6 项并优先处理当前视口附近节点；资产重新生成只失效对应缓存。旧标签页阻塞 IndexedDB 版本升级时会直接回退读取云端缩略图，不会让图片卡片一直停在加载状态；后续刷新在旧连接释放后恢复本地缓存。图片详情、Agent 读图和调度器参考图始终使用 COS 原图，缩略图不会进入生成请求。
- 生产环境图数据与对话分别使用乐观修订号。另一设备先保存后，旧修订保存会得到冲突提示并停止覆盖，用户可重新加载或另存副本；网络失败时当前内存修改继续保留并显示“尚未同步”，可手动重试。
- 右上角“画布 Agent”使用当前项目独立的工作流对话。收到完整剧本后先创建类型、主题、受众、情绪、预计时长和统一视觉风格分析节点。新短剧的首个人物批次只创建主角与核心配角；核心配角由 Agent 按与主角互动、主线影响和人物体系代表性自动选择。两张基础图未成功并经用户确认前，不创建其他资产。
- Agent 响应解析会忽略 JSON 边界处的零宽空格和 BOM，并从上游偶发附带的说明文字、分段文本内容中定位完整响应对象；这些传输外壳不会再让合法的剧本分析或导演续批误报为格式错误，字段、阶段和镜头校验仍照常执行。无法恢复的外壳或缺少导演操作时，漫剧仅自动使用紧凑导演快照恢复当前批次一次；第二次仍失败会安全停止并保留已完成节点，不会补字段、重复镜头或无限重试。
- 画布上的资产组即当前短剧的资产库，不跨项目共享。每项固定为“资产说明 → 图片调度 → 结果占位”，并保存 `assetRef`、资产类型、节点角色、基础角色身份、生成状态和可用性。资产按“剧本分析 → 基础角色 → 其他人物 → 场景 → 道具”从左到右分带，同类型纵向追加，缺少的类型不留空列。新布局首次加载时只自动重排当时活动项目一次，不覆盖其他项目或后续手动拖动。结果成功后即为可引用资产；重试或重新生成复用原占位。
- 新建资产调度器会把 Agent 返回的旧合法参数统一归一为 GPT Image 2、16:9、1K；用户仍可在生成前手工调整。全部资产使用均匀纯白背景，最终白底要求覆盖提示词中可能残留的王宫、森林或其他环境展示背景。人物综合板包含正面、左右侧面、中性与三种剧情表情；道具板包含 3/4 主视角、正背侧顶视图及材质、结构或功能细节特写，不再只生成一个平面图。
- 场景按稳定物理地点合并建档，同一地点跨场次复用一个 `assetRef`，永久格局变化才建立新版本。场景资产生成纯白背景上的 45° 鸟瞰空间母版，表达出入口、墙体、通道、固定家具和空间关系；人物、临时天气灯光、人物站位及分镜机位由后续分镜叠加。漫剧分镜通过 `storyId + assetRef + scene result` 引用母版。
- 主角和核心配角均为 16:9 / 1K 综合参考图，共用分析阶段确定的动态视觉风格，首次费用确认后并行生成。两张都成功后侧栏显示不产生费用的“确认基础角色并继续”；确认后才继续人物、场景和道具规划，并为其余资产提供第二张付费确认卡。失败基础图只重试失败项，成功图不重复提交。
- 所有非基础资产调度器固定连接图1主角和图2核心配角。人物使用“替换图1人物、与图2属于同一故事”的提示模板；场景和道具匹配两图的世界观、媒介、笔触、边缘、色彩与光影，但明确不复制人物。统一视觉风格按项目生成并可编辑，不把羊皮纸油画固定套用到所有短剧。
- Agent 编写图片或视频提示词时会自行判断角色 IP 风险：原创角色和未指向特定商业版本的公版角色保持原写法；存在风险时节点名称仍保留剧本称呼，实际提示词和随后会拼接的统一视觉风格直接改用年龄、脸型、发型、体型、服装、配色、表情、姿态和时代等原创特征，不使用角色、品牌、工作室或商业版本名称，也不会为原创近似方案再次询问。公版角色一旦被指定为特定商业版本，实际生成字段会同时去掉商业版本名称和公版角色名称。Agent 创建的资产和分镜调度器直接提交自身提示词，不再把资产说明或分镜原文额外拼接进模型请求；手工调度器仍按连线顺序读取上游文本。
- 资产默认使用 GPT Image 2、16:9 和 1K，调度节点仍可人工修改。单项使用调度节点运行；框选资产组的任意节点后会显示可点击的“生成选中资产”，并按 `assetRef` 去重批量生成，确认文案展示真实请求数、并行费用风险和成功资产覆盖数。正在提交/生成的资产排除，暂停任务只继续查询，不重复计费。刷新后会从分析节点和结果状态恢复基础图生成、质量确认或其余资产生成入口。
- 新剧本首轮仍只进行分析与资产规划。资产规划完成、基础角色确认且全部资产图片成功后，Agent 侧栏显示分镜类型选择：漫剧可用，TVC 显示“待开发”且不能提交。选择保存在分析节点的可选 `storyboardMode` 中，工作流图继续使用 `v1`，出现分镜后类型锁定。
- 漫剧按具有连续人物动作和运镜的 AI 动画短剧处理。选定漫剧后依次完成情绪节拍、场面调度、每批 1 至 2 镜的镜头规划和连续性检查；底层协议仍兼容最多 8 镜，镜头阶段使用严格 JSON Schema 固定操作及核心 ShotPlan 字段，并使用 8192 Token 输出预算，避免少量镜头的输出额度挤占长剧本上下文。每阶段结果立即作为可见节点保存，停止或刷新后从现有阶段继续；剧情节拍阶段保留完整剧本，后续阶段只携带当前阶段指令和当前项目的紧凑导演快照：保留分析、可用资产结果、节拍、场面调度和最近 4 镜完整结构，旧镜头压缩为连续性摘要，资产说明和图片调度器提示词不会随着批次重复发送。导演阶段只加载基础安全指令、导演核心、漫剧专项及当前阶段手册，镜头阶段额外加载公共摄影语言；图片、旧工作流和资产规划手册不会重复发送。程序会按当前最大镜头序号明确给出本批唯一允许的 `shot_id / sequence` 对，并把尚未覆盖的剧情节拍交给下一批；模型过早返回结束标记不会中断流程，补齐后按剧情节拍顺序重排和重编号。镜头总数不设固定目标。长镜直出普通镜头使用 10 至 15 的整数秒，短反应、插入、转场或瞬时动作允许 5 至 9 秒并必须写明原因；短片剪辑项目的每行严格使用 2 或 3 秒。
- 秒级时间轴由代码保证边界：镜头 `duration` 是唯一权威总时长，第一段固定从 0 秒开始，后续段首尾相接，最后一段固定结束于总时长；Agent 只决定各段按顺序发生的动作、表演、摄影和声音内容。最终视频提示词固定限定为当前镜头 `0–duration` 秒，保留本镜对白、旁白、音效和音乐，但不拼接转场、镜号、前后镜或跨镜声音说明；相似形状、动作承接、眼神、遮挡和声音撞击仅记录为导演切点与本镜可见首尾状态。
- 公共电影摄影层覆盖点、线、形状/框中框、空间、深度、平衡、色彩、光影和质感构图；大远景到大特写的景别；水平、俯仰、高度、倾斜和主观机位；固定、推拉、摇移、升降、跟拍、环绕、变焦和手持；以及相似、动作、眼神、反差、遮挡、黑场、逻辑、位置、时间、声音撞击和音乐节拍等转场意图。每镜只选择一种主要构图、核心景别、主要机位角度和主要运镜，最多增加一种轻微辅助运动；复杂运镜必须减少人物动作，跳轴、倾斜或失衡构图必须写明剧情动机。特写只在微表情、关键道具/信息、情绪高潮、喜剧反差或反应节拍中使用，特写/大特写和中远景及更远景别均最多连续 3 镜；固定机位必须有可读的镜内动作。每镜声音只描述本镜内部时间轴，不采用跨镜头声音提前或延续设计。
- 空镜可只引用场景资产，关键道具实际出镜时再增加道具资产，不强行连接人物。长镜直出需要 2 至 4 秒剪辑效果时仍规划至少 5 秒可生成素材；短片剪辑允许把该效果写为 2 至 3 秒分镜行，并由视频片段规则合并后生成。TVC 的商品露出、卖点演示、证明信息、品牌结尾、CTA、画面与法务文案、渠道规格，以及不得虚构功效、价格、数据、认证和代言等约束明确留在未来 TVC 专项，本轮不实现通用降级。
- 新漫剧在进入导演规划前先选择项目级节奏，并在首个镜头节点创建后锁定：`长镜直出`沿用普通镜头 10–15 秒、短镜 5–9 秒且需说明原因；`短片剪辑`每行分镜固定 2–3 秒。旧项目未保存节奏时按长镜直出读取，不改写已有镜头或任务。
- 新漫剧的分镜表行只创建“分镜文本”节点，不创建分镜图片调度器、图片占位或图片请求。分镜文本保存完整 ShotPlan；时间轴从 0 开始、连续覆盖到该镜整数秒时长，不能重叠、留空或越界。长镜直出每行直接连接一个视频调度器与视频结果；短片剪辑按连续场景合并多个分镜文本，创建最长 30 秒、至少 4 秒的 Seedance 2.5 视频片段。每个片段只计一次视频生成费用，参考资产按片段内首次出现顺序去重并最多连接 5 张。
- 工作流项目工具栏提供“分镜表”入口，统一从 ShotPlan 投影镜号、累计时间码、时长、资产引用、场景/时间、摄影、构图、表演、声音、切点、连续性和光影质感等 14 列；可横向浏览并导出 `.xlsx`。Excel 不嵌入原图，包含标题、汇总公式、冻结表头和自动换行；云端导出按当前登录账号与项目所有权读取，本地模式通过同一投影生成文件。
- 视频调度器按主要人物、次要人物、场景、关键道具顺序直接连接当镜 1 至 5 个成功资产，时长选择精确显示 ShotPlan 的整数秒。所有依赖就绪的镜头可在费用确认后同层并行；确认卡只统计视频请求。旧五节点“图片后视频”项目仍按原结构读取、运行和恢复。
- 漫剧镜头批次落图前会按主要人物、次要人物、场景、关键道具重新解析实际资产结果节点并规范引用顺序；模型返回的引用顺序差异不会造成无意义失败，缺失、跨项目或不可用资产仍会拒绝。
- 连续性检查覆盖人物、空间、轴线、视线、动作、道具、光线、台词和镜头衔接。结构错误会阻止创建视频节点；语义警告会保留在报告和镜头上并阻止批量生成，用户点击不产生费用的“确认连续性警告并允许生成”后才开放视频费用确认。
- 批量队列和任务 ID 随图持久化，刷新后恢复轮询与未完成队列。若页面在请求已发送但任务 ID 尚未保存时中断，对应分支标为“提交状态未知”并停止自动重试，避免重复计费。
- 文本素材可直接在卡片内编辑；图片素材支持上传一张不超过 10MB 的图片；视频素材支持上传一段不超过 100MB 的视频。本地模式素材 Blob 使用 IndexedDB；生产模式结果节点可保存兼容性的 `assetId`、文件名与 MIME 类型，旧 `resultUrl` 继续读取，工作流图版本仍为 `v1`。
- 导入图片和生成图片加载成功后按自然宽高调整节点，图片视觉区默认最长边为 288px，42px 标题栏单独计算；常见 1:1、9:16、16:9 节点外框分别为 288×330、162×330、288×204px。四角缩放继续保持标题栏下方图片区域的真实比例，短边最小 96px、长边最大 1200px；替换图片或重新生成短剧分镜图会重新适配，刷新不会覆盖已有显式尺寸。
- 素材节点和结果节点从右侧输出端口拖到调度节点即可连接。调度器在“输出类型”上方按持久化连线顺序显示卡片内部输入区，每个输入独占一行，并同时显示“图1/图2、文本、视频”等编号及来源节点名称；连线进入对应输入行左侧端口，界面图片编号与实际发送给模型的参考图顺序一致。没有输入时显示“暂无输入”，拖线命中整个调度器时会预览“新输入”行。自连接、重复连接和非调度目标会被拒绝。
- 工作流连线使用 4px 线宽；传递图片数据的素材/结果输入边和图片调度输出边统一为品牌蓝，文本、视频及其他边保持灰色。悬停或单击连线时会在中点显示删除按钮，图片线悬停显示更深蓝色。删除仅移除当前连线，不删除节点、结果、任务 ID 或媒体资产；删除输入后剩余同类端口会自动重新编号。创作画布继续使用原有 2px 连线。
- 素材节点和结果节点的右侧加号同时支持单击和拖动：移动不足 6px 时弹出文本、图片、视频生成菜单，选择后在右侧创建对应默认配置的调度节点并自动连线；移动超过 6px 时只执行原有拖线，不打开菜单。新节点读取锚点实际尺寸定位，遇到占用位置会向上下避让。
- 通用调度节点可选择文本、图片或视频输出，并配置对应模型、提示词、比例、清晰度、时长和输出数量。切换输出类型会恢复该类型的默认模型与参数，切换模型会恢复模型默认参数。
- 调度只读取直接相连的上游：按连线顺序拼接文本，读取图片作为参考图，最后追加调度节点自己的提示词，不递归执行更早节点。连接视频素材后会在请求前阻止运行并提示“当前模型不支持视频参考输入”，视频文件不会被发送。
- 当上游图片下载响应缺失或错误标注 MIME 时，工作流仅对带稳定 `.png`、`.jpg`、`.jpeg` 或 `.webp` 后缀的结果地址推断图片类型；未知文件仍拒绝作为参考图，避免把非图片数据发送给生成接口。
- 文本固定生成 1 个结果；图片和视频可选择 1–4 个。运行按钮明确显示任务数，每个数量对应一次独立请求和独立计费，并立即在调度节点右侧创建待处理结果节点。单个请求失败只影响自己的结果节点。
- 再次运行会追加新一批结果，不覆盖历史结果。删除调度节点只移除相关连线，已经创建的结果节点和远端任务会保留；删除未完成结果节点只停止本地查询，远端任务仍可能继续产生费用。
- 图片任务自动查询 10 分钟、视频任务自动查询 70 分钟后暂停，可在结果节点上手动继续。刷新或切回工作流模式后，未完成任务会继续查询。
- 工作流沿用创作画布的触控板平移与捏合缩放、框选与整组移动、四角缩放、固定右出左进连线及媒体详情预览；切换画布模式时视口恢复初始位置和 100% 缩放。
- 工作流平移和缩放会先按动画帧合并输入，并直接更新世界容器的 CSS 变换；停止交互约 120ms 后才提交一次 React 视口状态。节点拖动同样每帧最多更新一次，连线路径复用节点索引和缓存，单纯移动视口不会重新计算整张图。
- 工作流点阵背景使用独立合成层并按网格周期取模平移，视口变化不再通过画布根节点的继承 CSS 变量传播到全部节点。屏外节点由浏览器原生 `content-visibility` 跳过绘制，卡片缩略图延迟加载并异步解码；框选、临时连线和节点缩放也按动画帧合并。`will-change` 只在平移、缩放或节点拖动期间启用，停止后释放。
- 工作流 Agent 快照只在侧栏打开、发送请求或图结构变化时创建；资产可用性使用一次线性索引计算。图结构变化静默 300ms 后写入本地存储，页面隐藏或卸载时会立即补写最新状态。
- 本地模式的工作流节点、连线、参数和任务状态持续写入独立 `localStorage`，素材写入 IndexedDB；浏览器存储按协议、主机和端口隔离，因此应始终通过固定端口访问本地项目。生产模式以 PostgreSQL 和 COS 为权威数据源，不回退到浏览器数据。多参考图视频需要服务端为私有 COS 原图签发临时地址，因此本地结果必须先通过迁移工具写入云端 `assetId`；画布能显示本地图片不代表远端视频平台能够直接读取该图片。

## 调用与恢复

- 手动节点执行时只读取直接上游，并按连线创建顺序合并文本和图片；不递归读取更早节点。视频上游只在保存了提示词时作为文本上下文，不传递视频文件。
- 上游本地图片从 IndexedDB 读取，生成图片会尝试在客户端转换为附件；如果跨域或素材丢失导致无法读取，会在请求前停止并给出重新上传提示。直接上游与当前上传仍共享模型数量上限、单图 10MB 和合计 30MB 限制。
- 文本调用由服务端分别适配 OpenAI Chat Completions、Anthropic Messages 和 Gemini Generate Content 协议；图片附件按协议转换为 `image_url`、Base64 image source 或 `inline_data`。
- 图片和视频通过 `/v1/media/generate` 提交，通过 `/v1/media/status` 查询异步状态。
- COS SDK 只在已登录的云端视频请求需要签发私有参考素材地址，或已登录的成功任务需要转存结果时延迟加载。本地图片、文本、无参考图视频、普通任务轮询以及无效请求不会加载 COS 的 CommonJS 依赖，避免 Vinext/Rolldown 在生成或状态接口入口阶段因 `require("punycode/")` 不可用而中断。
- 图片请求按模型映射平台参数：Nano Banana 系列使用 `aspectRatio/imageSize`，GPT Image 2 将比例与 1K/2K/4K 组合为像素 `size`，Seedream 使用 `aspect_ratio/size`。视频请求为 Seedance 和 Vidu 写入所选 `resolution`。
- 图片任务每 5 秒查询一次，10 分钟后暂停；视频任务每 5 秒查询一次，70 分钟后暂停。暂停节点可以手动继续查询。
- 本地模式把节点、节点实际宽高、连线及两端侧别、任务 ID、状态和结果地址保存在版本化 `localStorage` 中；生产模式保存到当前账号所属项目。旧连线缺少侧别时按右→左恢复，旧节点未记录宽高时继续按 272×184px 默认尺寸读取。框选集合与框选框属于临时交互状态，刷新后不会恢复。
- 上传图片 Blob 保存在 IndexedDB 中，刷新后重建本地预览；本地 `blob:` 预览地址失效时，图片卡片和放大弹层会共用从 IndexedDB 重新生成的新地址。若原始 Blob 已被清除，则停止重试并提示重新上传。视口位置与缩放不持久化。
- 平台参数错误会返回经过清理的可操作提示；上游失败、余额不足或鉴权错误不返回服务端密钥、参考图数据或原始敏感响应。

## 当前边界

- 创作模式不支持双击创建空节点；工作流批量执行只推进短剧图片→对应视频这一层明确依赖，不递归执行任意手工图。两种模式均不提供撤销重做、远端任务取消、项目分享、团队权限或实时共同编辑；生产环境只提供账号隔离的跨设备同步与修订冲突保护。连线删除仅在工作流画布提供。
- 文本模式支持最多 5 张图片附件；每张图片仍创建独立输入节点并连接到文本输出节点。
- 生成质量等高级参数使用模型默认值。
- 画布 Agent 不提供图片裁剪、像素级重绘、视频时间线编辑、多个视频片段拼接、配音、字幕、音轨、最终成片导出、原始思维链或撤销重做；SSE 只流式展示受控过程摘要，资产规划继续按阶段/批次落图。
- 自动化测试使用模拟上游，本轮分辨率功能不执行真实付费生成；2026-08-06 曾用 1:1、1K、无参考图条件完成当时 5 个图片模型的单次真实生成验收。
