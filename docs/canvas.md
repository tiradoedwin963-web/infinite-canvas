# 无限画布开发说明

## 当前交付

项目提供一个全屏浅色点阵无限画布。首版只支持基础视口操作，不包含节点、工具栏、侧栏、选区、持久化或画布 Agent。

## 分支职责

- `codex/canvas-a`：基础画布背景、坐标变换、平移缩放和指针输入。
- `codex/canvas-b`：后续画布 Agent 交互与集成；当前与 A 保持相同的基础画布，不包含 Agent 功能。
- `main`：保留可回退的工程基线。

后续从 A 向 B 同步基础画布时，应使用明确的 Git 提交或快进操作。B 如需修改基础画布协议，必须先获得用户确认。

## 本地运行

环境要求：Node.js 22.13 或更高版本。

```bash
npm ci
npm run dev
```

验证命令：

```bash
npm run lint
npm test
```

## 画布交互

- 鼠标、触控笔或单指拖动：平移画布。
- 滚轮或触控板滚动：围绕指针位置缩放。
- 缩放范围：25%–400%。
